# Containers

Runtime containers and purpose:
- web: internal dashboard UI
- widget-service: embeddable chat UI
- shopify-app: commerce integration UI
- backend-api: API gateway/BFF
- workflow-engine: orchestration runtime
- ai-runtime: LLM execution
- memory: contextual persistence
- rag: retrieval and search
- worker-service: async execution
- notifications: outbound messaging
- integrations: external connectors
- analytics: metrics and event ingestion
- crm: customer state
- voice-service: voice processing
- shared-types: contracts shared across services
