# Questron Architecture

This directory is the source of truth for runtime architecture and ownership.
If code and docs diverge, update the docs first and align the implementation.

Sections:
- context: actors, external systems, and boundaries
- containers: runtime services and their responsibilities
- components: domain ownership and responsibilities
- runtime: execution flow diagrams and sequencing
- events: event catalog and contracts
- queues: async queue ownership
- agents: AI agent taxonomy and orchestration rules
- structurizr: system and container diagrams
